Concept 3: Reverse Function Machines

Slide 3 of 6

Function machines convert inputs into outputs. To find an unknown starting term, build a Reverse Machine with inverse operations!

Forward Function Machine (→)

5

→
× 4
→
− 3
→
17

Reverse Function Machine (←)

5
Original Input
←
÷ 4
←
+ 3
←
17
Target Output
🗣️ Demonstration Guide: "Emphasize two key rules for working backward: 1) Invert operations (× becomes ÷, − becomes +), and 2) Work backward right-to-left!"

Concept 4: Position-to-Term Rules
